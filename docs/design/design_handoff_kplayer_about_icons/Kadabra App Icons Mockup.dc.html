Platform spec
KP
macOS — .icns
Deliver full-bleed 1024×1024 square art — no pre-baked corner mask. macOS applies its own squircle clip and drop shadow automatically. Keep the glyph and IMI mark within the center ~82% safe area so nothing crops. Export the standard set: 16, 32, 128, 256, 512, 1024 (@1x/@2x) into a single .icns.
KP
Windows — .ico
Windows does not auto-mask — bake a subtle rounded-rect (~14% radius) into the art itself so it doesn't look like a stark square next to rounded neighbors. Export 16, 24, 32, 48, 256 px flattened into one .ico; include a plain-square fallback at 16/24 since the round corners disappear at that size anyway.
Rule of thumb: accent color always fills the whole icon (not a dark shade — needs to read at 16px), the two-letter code is the single largest shape, and the IMI mark is the only fixed constant — centered beneath the code, same relative size on every icon. Happy to render the full 1024px master art for any of these once the direction's approved.
