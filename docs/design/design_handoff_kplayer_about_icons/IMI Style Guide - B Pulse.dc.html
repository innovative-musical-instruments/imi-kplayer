08 / Product GUI
Controls
2.6s
Knob + LCD readout
Knob
Brushed-metal gray, knurled edge, single red indicator line. Never filled with accent color — the indicator is the only moving part.
Readout
Black LCD chip, monospace value, sits directly under its knob. Units always shown (%, dB, ms, Hz, Q).
Panel
Each function (Tone, Delay, Reverb…) is a rounded dark group with a capitalized label above it. No panel borders touch — a hairline gap always separates them.
Toggle
Small round switch + label, e.g. "Sync" — off state gray, on state fills with the instrument's accent.

10 / Product GUI
Host & mixer app
A second language
The multi-channel host is a utility, not an instrument face: cool navy-blue panels, thin outlines, dropdowns and linear faders — no knobs, no wordmark treatment.
Shared DNA
Each channel still loads its plugin by name; mute state uses the same Pulse Orange as the brand accent — the one deliberate color bridge between the two UI languages.
